    更加个性化的配置

    网易云音乐插件♪

    找到想要插入的音乐对应的网址，例如：https://music.163.com/song?id=1930816340&uct2=U2FsdGVkX19HslQlU1a7OEAhHeHSZItr8fFCmhIDNPY=

    左侧黑胶唱片下面有一行蓝色超连接：生成外链播放器，点进去，选择是否自动播放以及想要的尺寸，复制下面的 HTML 代码，将其插入到想要插入的地方。

    例如下面的 HTML 代码会插入一个 310x66，自动播放的插件：

    HTML
    1
    <iframe frameborder="no" border="0" marginwidth="0" marginheight="0" width=330 height=86 src="//music.163.com/outchain/player?type=2&id=1930816340&auto=1&height=66"></iframe>

    另外，您可以修改上述代码中的 width 和 height 参数来调节插件大小；auto 参数为 1 时自动播放，为 0 时非自动播放；id 为您希望播放音乐的 id，可以通过上面第一个网址得知。注意其中的 type=2 是不能修改的。

    背景图片♪

    学 css 五分钟弄出来的东西，然后调试了半小时。

    body {
  background: rgba(256, 256, 256, alpha) url('background_url');
  background-blend-mode: screen;
  background-size: cover;
  background-repeat: no-repeat;
  background-position: center;
  background-attachment: fixed;
}

    其中的 alpha 为您希望的透明度，数值越大越偏向白色（#FFFFFF）（如果想要其他颜色，可以更改 rgba() 函数中的参数）； background_url 为您背景图片的地址。
